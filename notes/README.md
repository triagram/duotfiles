# notes/ — 决策记录

一个软件一个文件，`notes/<软件名>.md`。

**这里写什么：** 你做过的判断，尤其是「为什么这一块必须分平台、不能合并」。

**为什么需要：** 每次让 AI 帮你比对两个平台的配置，它都会重新提出「这几行看起来一样，
可以合并到 common/」。如果你上次已经判断过「不行，因为 macOS 的 Option 键在 Linux 上
不存在」，而这个判断没被记下来，下次它还会再提一遍，你还得再想一遍。

记下来之后，AI 在提建议前会先读这里，重复的建议就不会再出现。

**这里不写什么：** 使用说明（那是 README.md）、设计理由（那是 DESIGN.md）、
变更历史（那是 git log）。

## 建议格式

```markdown
# <软件名>

## 平台差异

| 配置项 | linux | macos | 能否合并 | 判断日期 |
|---|---|---|---|---|
| ... | ... | ... | ❌ 因为... | 2026-08-09 |

## 部署注意事项

<这个软件部署时有什么特别的>
```
